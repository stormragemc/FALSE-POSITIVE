# Browser furniture exports

These GLBs adapt the existing project furniture for the WebXR build. No characters or animations are included.

| Export | Original source | Author | License |
| --- | --- | --- | --- |
| desk.glb | [metal_office_desk](https://polyhaven.com/a/metal_office_desk) | Ulan Cabanilla | CC0 1.0 |
| chair.glb | [SchoolChair_01](https://polyhaven.com/a/SchoolChair_01) | Ethan Place | CC0 1.0 |
| sofa.glb | [sofa_03](https://polyhaven.com/a/sofa_03) | Fran Calvente | CC0 1.0 |

The project's original source and asset manifest remain under `Assets/_Project/Art/PolyHaven/`. These exports preserve the model surfaces while reducing embedded texture dimensions for browser loading. They are ordinary Git objects so a WebXR deployment does not need an additional model download service.
